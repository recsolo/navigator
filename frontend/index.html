    Architecture

    Built local-first, packaged later.

    Frontend shell

    Questionnaire, recommendations, and workflow UI live in `frontend/` so Cursor and Codex can iterate quickly.

    Python backend

    FastAPI in `backend/` owns questionnaire schema, scoring, and workflow generation with explicit logic.

    Desktop shell

    Electron loads `frontend/`, starts the FastAPI backend (venv or bundled exe), and stores SQLite under the app user data path when packaged.
