# MVP

## Goal

Validate that users will trust Navagator to choose a better AI stack than they would choose on their own.

## Version one scope

Build only these capabilities:
- onboarding questionnaire
- recommendation engine returning top three tools
- fit explanations
- first workflow builder
- saved local session state later

## Deliberately out of scope

Do not build these yet:
- full scraper agent
- live community network
- centralized analytics moat
- subscription billing
- cross-user learning loop

## Success signal

A user should be able to complete onboarding and say:
"I know what to use next and how to start."
