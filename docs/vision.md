# Navagator Vision

Navagator is installable software for people overwhelmed by AI tool sprawl.

## Promise

Give each user a practical answer to three questions:
- what tools should I use
- why these tools instead of the alternatives
- what exact workflow should I run first

## Product shape

Navagator should feel like a personal guidance engine, not a tool directory.

The user gives:
- goal
- skill level
- budget
- workflow preference
- time constraints

Navagator returns:
- top recommended tools
- fit explanation
- comparison logic
- first workflow
- later, briefing updates and outcome tracking

## Installable-product framing

Version one should behave like local-first software with optional online enrichment.

That means:
- the app should work with a bundled or locally cached catalog
- recommendations should still run without a hosted multi-tenant backend
- packaging for desktop can happen once the core flow is stable
